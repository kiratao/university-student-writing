# 插件市场发布与 README 实施计划

## 目标

将现有 Skill 仓库转换为可移植的仅技能插件源码仓库，生成经过验证的 OpenAI 插件上传包，并提供面向学生与开发者的中文主导 README。

## 实施步骤

1. 保留根目录 Git 历史、`.gitignore` 和设计文档，把 Skill 本体移动到 `skills/university-student-writing/`。
2. 创建根 `plugin.json` 可移植清单和 `.codex-plugin/plugin.json` 兼容清单；两份清单保持版本、名称和界面文案一致。
3. 添加 MIT `LICENSE`，版权名使用已批准设计中的 `tyz`。
4. 编写 `README.md`，覆盖价值主张、能力矩阵、示例、安装、准确性边界、开发验证、隐私与发布状态。
5. 添加商店提交文案、隐私声明和使用条款，供发布者生成公开 URL 并填写提交门户。
6. 添加确定性的 `scripts/package_plugin.py`，只打包提交所需文件并拒绝意外覆盖。
7. 更新 Skill 内部测试和路径引用，仅在目录移动导致需要时修改，避免改变其工作流行为。
8. 运行 Skill 校验、插件校验、全部单元测试、代表性 XeLaTeX 编译测试和压缩包内容检查。
9. 使用独立审查检查 README 声明、清单一致性、隐私表述和包结构；修复高优先级问题。
10. 提交 Git，并将最终仓库与发布包同步到用户指定目录。

## 完成标准

- 根目录存在有效的 `plugin.json`、兼容清单、README 和 MIT License；
- Skill 位于标准 `skills/<skill-name>/SKILL.md` 路径；
- README 不声称插件已经通过审核或已经上架；
- 插件不声明不存在的 MCP、应用、账号连接或网络服务；
- 上传包不包含 `.git`、测试缓存、编译缓存、本机绝对路径或未完成占位标记；
- 所有自动校验和代表性实际编译通过；
- Git 工作树干净，最终提交号可追踪。
