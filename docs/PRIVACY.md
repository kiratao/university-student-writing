# 隐私说明

更新日期：2026-09-21

## 数据处理

`university-student-writing` 是仅包含 Skill、模板和本地脚本的插件。当前版本：

- 不包含远程 MCP 服务器；
- 不要求登录第三方账号；
- 不包含遥测、广告或用户行为分析；
- 不会由随附脚本自动上传文档、提示词或生成结果；
- 仅在用户授权的本地文件范围内创建、读取和校验 LaTeX 项目。

ChatGPT、Codex、操作系统、代码托管平台和用户自行选择的其他工具可能适用各自的隐私政策，本说明不替代这些平台的政策。

## 敏感信息

用户应避免在不受信任的环境中处理身份证号、家庭住址、医疗信息、未公开成绩、调查原始记录、账号凭据或他人的私人资料。学校、实习单位或研究项目有保密要求时，应先遵守相应制度。

## 外部资料

Skill 包含公开规范和高校页面的链接，用于解释格式依据。是否访问这些链接由实际运行环境和用户请求决定；随附生成与校验脚本本身不主动访问网络。

## 联系与变更

公开发布后，问题与隐私反馈应通过项目代码仓库的 Issue 或发布页面提供的支持渠道提交。若未来版本加入远程服务、账号连接或遥测，本说明必须在发布前更新。
