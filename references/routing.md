# 文体路由

先确定交付目的，再选文体。不要仅凭用户使用了“报告”“稿子”等泛称直接套模板。

| 需求信号 | 优先文体 | 模板家族 | 需要进一步区分 |
|---|---|---|---|
| 课程作业、研究问题、引用文献 | 课程论文或学术论文 | `academic` | 中文、APA、MLA、IEEE或教师模板 |
| 汇报实验步骤和结果 | 实验报告 | `report` | 教学实验或研究实验 |
| 汇总他人研究 | 文献综述 | `academic` | 叙述性、范围综述或系统综述 |
| 记录实践经过并反思 | 社会实践报告 | `report` | 不等同于调查报告 |
| 使用问卷、访谈、观察回答问题 | 调查报告 | `report` | 方法、样本、证据和局限必需 |
| 只写个人感受和成长 | 心得体会 | `report` | 不得伪装成实证调查 |
| 组织一项活动 | 活动策划书 | `organization` | 审批表或学校模板优先 |
| 告知时间地点和办理要求 | 通知 | `official` | 校内通知不自动等同党政机关公文 |
| 留存会议事实 | 会议记录 | `official` | 与概括决定事项的会议纪要区分 |
| 报道新近校园事实 | 消息 | `news` | 与强调细节和主题的通讯区分 |
| 向多家媒体提供统一事实材料 | 新闻通稿 | `news` | 不能写成广告或虚构引语 |
| 向老师或行政人员沟通 | 正式邮件 | `letter` | 中英文礼貌和主题行不同 |
| 求职或实习 | résumé、简历或求职信 | `career` | 普通 résumé 与学术 CV 区分 |
| 现场口头表达 | 演讲、主持或答辩稿 | `speech` | 按时间长度和听众调整 |

## 模糊请求

- “写实践报告”：先确认是否包含调查研究；若没有，使用经历—工作—结果—反思—改进结构。
- “写新闻稿”：确认是校园消息、通讯、对外通稿还是微信公众号推文。
- “写总结”：确认主体是个人、班级、部门、活动还是项目；工作总结应包含目标、事实、结果、问题和改进。
- “写申请”：确认接收人、请求事项、依据、个人信息、附件和审批流程。
- “写论文”：确认课程、学科、语言、引用体例、篇幅及教师模板。

只询问会改变文体或强制格式的信息。其余缺失事实保留为待填写字段。
